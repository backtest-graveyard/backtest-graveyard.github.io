# backtest-graveyard.github.io

The links-and-corrections page for *The Backtest Graveyard*.

The book prints this address in its front matter and in Appendix B. It exists so that
a corrected figure, or a moved source file, can be fixed without reprinting the book.

**Deploy:** push to a repo named `backtest-graveyard.github.io` under a user or org of
the same name, with Pages enabled on the default branch. `.nojekyll` is present so the
file is served as-is.

**Editing corrections:** add an `<li>` to `#corrections` showing chapter, original
figure, corrected figure, and cause. Remove the placeholder `<li class="none">` when
the first correction lands. Never amend a figure silently — the point of the page is
that the change is visible.
