Privacy policy

The Backtest Graveyard — last updated 8 October 2026

Short version: “Backtest Graveyard Uploader” is a private command-line tool the channel owner runs on his own computer to publish videos to his own YouTube channel. It has no users other than its author, no server, and it collects nothing from anybody.

What this page covers

This policy describes “Backtest Graveyard Uploader”, an application registered with Google so that it can call the YouTube Data API. It does not describe the YouTube channel itself, which is governed by YouTube’s own terms.

What the application does

It uploads episode files, sets titles, descriptions, tags, thumbnails, caption tracks and playlist membership on a single YouTube channel: the one owned by the person running it. It is run by hand from a terminal and is not offered to, installed by, or usable by anyone else.

What data it touches

  • Google account data. After the author signs in and grants access, the application receives an OAuth token permitting it to manage his own YouTube channel. The token is stored only in a file on his own computer and is never transmitted anywhere except to Google.
  • Video and caption files. Episode media and subtitle files are sent to YouTube in order to publish them. That is the entire purpose of the tool.
  • Nothing from viewers. The application never reads viewer data, comments, messages, analytics or personal information about any other person.

What it does not do

  • It has no servers, no database and no hosted component.
  • It does not sell, share, transfer or disclose data to any third party.
  • It contains no analytics, telemetry, advertising or tracking of any kind.
  • It does not use Google user data to develop, improve or train any artificial-intelligence or machine-learning model.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and revocation

The stored token lives on one computer and is deleted whenever the author deletes the file. Access can be withdrawn at any time from the Google account permissions page, which immediately and permanently ends the application’s access.
